# One-time site upload

The repository is connected to ChatGPT and the live family-tree landing page plus JavaScript files have begun to be committed here.

## One-time image/site import

1. Install GitHub Desktop on the Windows computer that holds the Bell Family Archive.
2. Clone `rickeybell/bell-family-archive`.
3. Extract the two latest Bell Family Archive ZIP parts into one temporary folder.
4. Copy the contents of that combined folder into the cloned `bell-family-archive` folder. Keep the existing `.git` folder created by GitHub Desktop.
5. In GitHub Desktop, review the changed files, use a summary such as `Import current Bell Family Archive`, then Commit to `main` and Push origin.
6. After that one-time import, normal HTML/CSS/caption/tree changes can be committed directly through ChatGPT's GitHub connection without repeatedly downloading the entire archive.

## Preservation note

Keep the full-resolution genealogy originals, complete EXIF/XMP/IPTC tags, locations, and GPS data in the separate master photo archive. The GitHub repository is the website working copy.
